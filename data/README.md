# Data for Empirical Analyses
This directory contains pm2.5.csv, the dataset used in the first empirical application in the main manuscript. The dataset used in the second empirical application, ethylene_methane.txt, can be downloaded from the website: https://archive.ics.uci.edu/dataset/322.

The Beijing PM2.5 dataset contains hourly environmental observations from March 5, 2013 to December 31, 2015. The chemical sensor dataset contains readings from 16 chemical sensors exposed to mixtures of ethylene and methane in air at varying concentrations.
